# Pantry

Pantry keeps a home cook's recipes on their own laptop. Its users are
home cooks, not programmers: they type a few commands from a guide, and
most have never opened a terminal for anything else.

```
pantry add-recipe --url https://example.org/soup
pantry find-recipes lentil
pantry make-shopping-list soup bread
```

Settings work the same way: `pantry font-size` prints the size, and
`pantry font-size large` sets it.
